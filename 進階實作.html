一、 本講教學核心

在第一講中我們成功將數據呈現在儀表板上。第二講我們將推進至「智慧化分析」：讓儀表板自動計算經濟指標利差（如殖利率倒掛），並呼叫 Google Gemini API 自動撰寫專業的總體經濟短評。

二、 核心程式碼升級：結合 Gemini API 自動產出報告

1. 更新 requirements.txt

確保專案目錄下的 requirements.txt 包含以下必備套件：

streamlit
pandas
requests
yfinance
google-genai

2. 整合 Gemini 2.5/3.8-Flash 生成即時總經短評

在 app.py 中新增 AI 自動撰寫 200 字摘要的功能：

import streamlit as st
import time
from google import genai

# 從 Secrets 安全取得 API Key
google_key = st.secrets.get("GEMINI_API_KEY")

if st.button("🤖 產生 AI 總體經濟即時短評"):
    if not google_key:
        st.error("請先在 Streamlit Secrets 設定 GEMINI_API_KEY")
    else:
        with st.spinner("AI 正在分析最新 CPI 與經濟數據中..."):
            try:
                client = genai.Client(api_key=google_key)
                prompt = f"""
                你是一位專業的總體經濟分析師。請根據以下最新數據撰寫一份 200 字的繁體中文短評：
                - 美國最新 CPI 通膨率: {cpi_val}%
                - 10年期美債殖利率: {bond10_val}%
                - 2年期美債殖利率: {bond2_val}%
                重點請分析目前通膨動態與聯準會政策可能走向。
                """
                
                # 採用最新穩定版 Flash 模型
                response = client.models.generate_content(
                    model='gemini-2.5-flash',
                    contents=prompt,
                )
                
                st.success("分析完成！")
                st.markdown(response.text)
                
            except Exception as e:
                st.warning(f"目前連線壅塞，重試中... ({e})")
